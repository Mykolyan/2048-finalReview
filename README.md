# 2048 Game

A browser implementation of the classic 2048 puzzle game. Use the arrow keys to slide numbered tiles, combine matching tiles to reach the 2048 tile, and try to beat your high score.

## Live Preview

[Play it here](https://Mykolyan.github.io/2048-finalReview/)

## Technologies Used

- HTML5
- SCSS
- JavaScript (ES6+)
- Gulp / Parcel (build tooling)

## Getting Started

Clone the repository:

```
git clone https://github.com/Mykolyan/2048-finalReview.git
cd 2048-finalReview
```

Install dependencies:

```
npm install
```

Run the project locally:

```
npm start
```

## Features

- Classic 2048 gameplay with arrow-key controls
- Mobile-friendly swipe controls for touch devices
- Smooth tile spawn and merge animations
- Live score tracking
- Win and lose state messages
- Restart button to start a new game at any time
